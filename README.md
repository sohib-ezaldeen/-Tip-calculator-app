# 💰 Tip Calculator App

A simple and interactive tip calculator built with **HTML, CSS, and JavaScript**.
This project allows users to calculate the tip amount and total per person بسهولة وبشكل فوري.

---
## 🌍 Live Demo

👉 https://sohib-ezaldeen.github.io/-Tip-calculator-app/

## 🚀 Features

* 💵 Enter bill amount
* 🎯 Select tip percentage (buttons or custom input)
* 👥 Split the bill between multiple people
* ⚡ Instant calculation (real-time updates)
* ❗ Validation for invalid inputs (like zero or empty values)
* 🔄 Reset button to clear all fields
* 📱 Fully responsive design

## ⚙️ How It Works

1. Enter the bill amount
2. Choose a tip percentage or enter a custom value
3. Enter the number of people
4. The app calculates:

   * Tip per person
   * Total per person

## 🧪 Validation Rules

* Bill must be greater than 0
* Tip must be selected or entered
* Number of people cannot be zero

---

## 🔄 Reset Functionality

The reset button:

* Clears all inputs
* Resets calculated values
* Removes selected buttons
* Restores initial state
